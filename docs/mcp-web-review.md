# Web 周月实际时间回顾增量

新增授权接口 `GET /api/review?from=YYYY-MM-DD&to=YYYY-MM-DD`，日期范围最多 366 天。只读查询记录表，返回每日记录分钟、时间区间并集覆盖分钟、重叠分钟、记录数及分类实际分钟；预计快照不计入实际。零时长不占用覆盖，跨午夜只裁切当日覆盖，不改原始记录分钟。

Web 页面新增以当前选中日期为基准的自然周／自然月回顾：每日记录分钟柱状图、累计记录/覆盖小时、分类实际时长。回顾不依赖计划任务估算，也不回写数据。

合成数据测试覆盖两条时间重叠时“记录总长 120、覆盖 90、重叠 30”，API 范围校验、分类合计和实际时间修订后的统计；`npm run build`、`npm test` 均通过。未进行真实浏览器交互测试。

**边界**：只提供实际时间维度的初步周月回顾；原插件完整趋势、支出、生产力、事项排行、待确认与完整 Markdown 日记统计尚缺。Web 当前数据集与 Vault 不同步，不可称为原插件回顾完全对齐。
