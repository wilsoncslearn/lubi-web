# Web JSON 预览与空库恢复

本功能仅支持**当前 Web 版自身**导出的 `lubi-web-data` v1，不接受原 Obsidian 插件的 `lubi-data` 文件或直接读取 Vault。用户真实 Vault 数据仍需另行设计迁移并明确授权。

## 操作流程

1. 在旧 Web 项目登录并下载“导出 Web 数据 JSON”；将文件保存在受保护的位置。文件包含全部项目、任务、时间记录及关联，属于个人敏感数据。
2. 在**空白**的新 Web SQLite 数据库上登录，侧栏选择该 JSON 文件。服务端校验格式、字段、日期、ID 唯一性与项目/任务引用，显示项目/任务/记录数量和目标库是否为空。预览不写库。
3. 核对数量后按“确认恢复”并确认弹窗。预览仅在当前登录会话中有效 10 分钟；文件内容变化或会话变化须重新预览。
4. 导入在一个 SQLite 写事务中执行。任一约束失败则回滚；目标库只要已有项目、任务或记录便拒绝写入，不覆盖或合并旧数据。完成后可再次导出核对数量和关键关联。

页面选取的文件限制为 7 MB；API 请求体限制为 8 MiB。更大的导出文件目前不能通过此流程恢复。服务器上无后台文件读取或自动导入，不接触原 Vault。

## 验证与限制

合成数据测试覆盖：未登录拒绝、无效关联拒绝、预览与文件哈希一致、整库导出→空库恢复后逐表相等、重复导入拒绝、数据库唯一约束失败时事务回滚。`npm run build` 与 `npm test` 通过。

这是 Web schema v1 的结构化恢复，不包含原插件日记、设置、密钥，也不包含 SQLite 的运行环境或服务器配置。它不能替代定期的 SQLite 在线备份、异地备份、恢复演练和生产安全审计；目前未进行真实浏览器或生产部署验收。
