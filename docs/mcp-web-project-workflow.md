# Web 项目归属增量

本轮在独立 Web 原型中增加 `projects` 表和任务的可空 `projectId`；旧原型 SQLite 数据库启动时新增该列，已有任务不被覆盖且保持无项目归属。项目使用 ID 关联，标题不作为任务外键。

- API：项目列表、创建、改名、删除；任务创建与更新可设置项目或移出项目。不存在的项目 ID 会拒绝；有任务的项目不能删除，避免静默使任务失去归属。重复标题按不区分大小写拒绝。
- 页面：侧栏创建/选择项目，新建任务自动归入所选项目；“全部项目”可查看当天全部任务。项目改名、删除和任务换项目目前仅有 API，尚无对应界面控件。
- 验证：`npm run build`、`npm test` 通过。API 集成测试使用临时 SQLite，覆盖未登录拒绝、旧数据库字段迁移、项目创建/任务归属、阻止删除非空项目、移出任务后删除及无效项目拒绝。无真实 Vault 数据写入，也未做浏览器实机检查。
- 边界：这仍不是原插件 schema v14 的完整项目/任务模型；无父级转换、重复任务、导入、双向同步或完整生产安全措施。
