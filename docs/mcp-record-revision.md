# Web 时间记录修订与关联删除保护

本轮实现 `/api/records/:id` 的 PATCH 与页面记录编辑：可改事项、分类、日期、开始时间、实际分钟；`taskId`、`estimatedMinutes`、`created` 不可在这一路径修改。服务端重新校验日期、时间和时长，修订实际分钟后当日汇总会按新值计算；历史预计快照不回填。

删除任务前检查有无时间记录关联：存在即拒绝（409），防止静默将外键置空而丢失关联。当前不提供自动搬迁关联记录；请勿为解除限制而未经核对删除历史记录。删除记录本身仍为直接删除，没有撤销。

验证：`npm run build`、`npm test` 通过。合成数据覆盖任务预计修改后的历史快照保留、记录修订、无效日期拒绝、汇总更新、有关联时拒绝删除任务。未进行真实浏览器、Obsidian、移动端或生产环境验收。

与原插件仍存在较大差距：原 Markdown 日记非记录行保留、跨午夜拆分、关联记录重编辑、删除撤销、支出、待确认状态等未移植；不能导入真实 Vault 数据。详见 [总体差距](mcp-parity-gap.md)。
