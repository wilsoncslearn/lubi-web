## 辅助材料

- [界面对照](界面对照.html)：离线验收图库，使用合成数据，不是另一套应用。
- [历史阶段文档](archive/README.md)：原型、早期设计及阶段性记录，仅供追溯；其中旧模型、旧入口和“尚未实现”的描述不能用来判断当前版本。

## 更新规则

- 使用方式改变，更新项目 README。
- 模块边界或数据约束改变，更新架构说明。
- 测试结果改变，在验收记录中注明版本、环境和证据，不能覆盖成未经执行的通过结论。
- 不再新增另一份与以上三份平行的“当前状态”文档。
