# 完整对齐状态与记录关联增量

## 本轮已落地

Web 时间记录表单可选当日任务，API 根据任务当时的 `estimate` 自动保存 `estimatedMinutes` 历史快照；用户请求中的同名字段不会替代服务器计算值。独立记录无任务关联也无预计快照。后续修改任务预计不会回填旧记录；当日实际统计只累计实际分钟。任务缺省分类可用作关联记录的默认分类。

使用临时 SQLite 的 API 集成测试检查：90 分钟预计生成首条快照、任务预计改为 120 后下一条快照改变而旧快照不变、伪造预计字段无效、独立记录与当日实际汇总。`npm run build` 和 `npm test` 通过。未运行真实浏览器、真实 Obsidian，也未处理个人数据。

## 与“原插件全部功能”之间的主要差距

- 原任务 schema v14 大量字段、父级兼容和项目转换仍未移植；Web 当前只是精简任务模型。重复规则仅有基础日/周/月与逐次完成；完整排期移动、撤销、显式跨度与复杂验收逻辑尚缺。
- 原 Markdown 日记记录的原始行保留、跨午夜、支出、未知字段、待确认标记、记录编辑、历史记录兼容与迁移逻辑尚缺。Web 新记录目前只是 SQLite 结构化数据，不回写原 Vault。
- 原计划页的九种展示/范围组合、甘特交互、日报时间轴、回顾指标与分类图表等尚缺；目前只有简化的当天任务和记录列表。
- AI 草稿、模型选择、SecretStorage、插件在线更新、设置、导出/导入、数据备份恢复、安全部署和移动端验收尚未做。部分 Obsidian 特有功能不应原样搬到 Web，需要先确认替代产品行为。
- 现有登录仅供本地原型：缺限速、持久会话/生产 CSRF 方案、正式部署与备份恢复演练。不可公开部署。
