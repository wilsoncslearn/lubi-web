## 四、明确的宿主边界

核心业务与界面复用原插件，但 Web 不冒充 Obsidian 系统能力：

- 文件保存到独立 SQLite 虚拟 Vault，不直接共享原仓库；日记和成果内链用 Web 文件编辑器打开，导出使用浏览器下载。
- 命名密钥使用服务端 AES-256-GCM 加密库，不是 Obsidian 的操作系统钥匙串。
- 桌面插件安装 / 自更新仍在 Obsidian 内处理，网页不会执行桌面安装器或修改原安装目录。
- 和原插件一样，「后台任务」是手动运行 / 审核 / 返工工作流，不凭空执行或控制 Agent。
- 尚未验收真实手机、自定义 Obsidian 主题、第三方插件组合或真实 AI 提供方。不能把窄屏浏览器 / 模拟接口通过解释为上述范围也已通过。

没有发布公网或创建 Release。后续 Git 提交与推送仅包含程序、测试和合成截图文档，不纳入本机密码、数据库、备份或密钥。没有将「通过当前环境与场景验收」夸大为所有环境、所有像素绝对无差异。
