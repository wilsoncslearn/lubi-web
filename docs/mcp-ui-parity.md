# 当前插件界面 → Web 对照进度

基准：原 Vault 当前开发工作区的 Lubi 插件区域（不含 Obsidian 外壳）。本轮核对了源码 `src/ui/view.ts`、当前 `src/styles/` 和已有合成数据的 MONO 列表日截图。原仓库的个人数据、未提交样式改动未修改。

## 已改的 Web 主界面

- 将原来独立的绿色侧栏工作台替换为局部黑白 MONO：顶栏日期导航、计划/回顾切换、计划页标题与四列摘要；列表·日优先显示「需我处理」与「当天任务」，右栏分成 Agent 后台、我的用时、未安排。
- 增加日历/甘特图/列表和日/周/月的切换入口、日历范围投影、基础甘特日期格、每日时间轴，以及回顾周/月/年周期切换。新建任务和记录共用黑白弹窗。
- 后端仍使用独立 SQLite。浏览器自动化在 1400×900 下验证登录、计划、回顾、日历切换和无页面脚本错误；构建与现有测试通过。本地演示服务保持运行。

## 尚未达到“一模一样”

- 当前日历、甘特图和时间轴是**基础投影**；缺原插件时间网格拖选、拖动与伸缩、并行排布、撤销、项目分组投影和范围导航细节。
- 任务模型缺完整 v14 字段；后台审核、Agent 状态、计划负载、未安排的编辑/拖放等未接通。页面用“—”或禁用状态标记未接入项，不能将其当作真实 0 值。
- 原版 JSON 任务导入和 AI 创建仍未接入，顶栏按钮已禁用；菜单中的“原插件导出预览”仅做只读分析。
- 原插件的支出、待确认、Markdown 日记、完整回顾与弹窗仍未迁移；本轮没有真实 Vault 数据。即使局部视觉接近，功能一致性仍需逐项实现和真实 Obsidian/浏览器对照验收。
