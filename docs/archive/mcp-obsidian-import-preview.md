# 原 Obsidian 插件导出预览（只读）

原插件导出的 JSON envelope 是 `{format:"lubi-data",version:1,exportedAt,taskStore,records}`，任务为 schema v14。此文件与 Web 自己的 `lubi-web-data` 导出格式不同，**不能交给 Web 恢复接口写入**。

新 Web 提供 `POST /api/obsidian/preview` 与侧栏文件选择器，只读取上传的 JSON 并返回项目、任务、记录及存档容器的数量和不兼容项计数。当前识别的风险包括父级任务、排期开始时间、地点、备注、后台执行、旧关联、支出、自定义/待确认字段、跨午夜记录和无效引用。预览明确返回 `readyForDirectImport:false`，没有“应用导入”按钮，不写 SQLite，也不读写原 Vault。

上传文件可能包含个人任务、日记与支出信息。仅在可信的本地 Web 环境使用；当前原型未经过生产安全审计。文件大小需小于页面限制，预览不等于备份。**本轮只用合成数据测试，未检查、备份或导入真实 Vault 数据**。

完成正式迁移前仍需：保留原始字段或建立逐字段映射；实现并测试 Markdown 日记与任务 v14 的业务规则；仓库外备份原 Vault；预览差异和孤儿引用；事务式导入到隔离数据库；核对任务数、关联及统计；得到用户对真实写入的单独确认。当前无法声称原数据迁移已经完成。
